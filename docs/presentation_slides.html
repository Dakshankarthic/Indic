  • Palm-leaf (Borassus flabellifer) and handmade paper exhibit non-uniform decay.

I(x,y) = R(x,y) \cdot L(x,y) + \eta(x,y)

Hierarchical Document Layout and Semantic Partitioning
Formal Layout Hierarchy Definition

Given raw digital capture I \in \mathbb{R}^{H \times W \times 3}, determine optimal hierarchical decomposition \mathcal{T}:

\mathcal{T} = \left\{ \mathcal{R}_{\text{frame}}, \{\mathcal{R}_{\text{text}}^{(k)}\}_{k=1}^{K}, \{\mathcal{R}_{\text{illus}}^{(m)}\}_{m=1}^{M}, \{\mathcal{R}_{\text{damage}}^{(d)}\}_{d=1}^{D}, \{\mathcal{L}_{j}\}_{j=1}^{J}, \{\mathcal{W}_{j,p}\}, \{\mathcal{G}_{j,p,q}\} \right\}
  • Region Boundaries: Closed planar polygonal chains \mathcal{P} = \{(x_1, y_1), \dots, (x_V, y_V)\}.
  • Reading Order Optimization: Topological order permutation \mathcal{C}_1 \prec \mathcal{C}_2 \prec \dots \prec \mathcal{C}_C.
  • Schema Standardization: Conforms strictly to the PRImA PAGE-XML 2013 schema framework.
Section 2: Methodology
Image Preprocessing and Local Illumination Compensation
Adaptive Gaussian Binarization and Morphological Filtering
Adaptive Gaussian Thresholding
  • Compensates for spatial illumination gradients L(x,y).
  • Evaluates local neighborhood statistics in window (2r+1) \times (2r+1) with r=25, C=5:
B(x,y) = \begin{cases} 1 & \text{if } I_{\text{gray}}(x,y) < \mu_G(x,y) - C \\ 0 & \text{otherwise} \end{cases}
\mu_G(x,y) = (I_{\text{gray}} * G_\sigma)(x,y)
Morphological Noise Suppression
  • Isolates true foreground ink from biological fiber artifacts.
  • Elliptical structuring element \mathcal{E}_{3\times 3} eliminates isolated single-pixel noise:
B_{\text{clean}} = (B \ominus \mathcal{E}_{3\times 3}) \oplus \mathcal{E}_{3\times 3}

Patch Discretization Mechanics
  • Image dimensions aligned to patch multiples (P = 14 px).
  • Discretization equations:
H' = \lfloor s\cdot H / P \rfloor \cdot P, \quad W' = \lfloor s\cdot W / P \rfloor \cdot P
\mathbf{Z} = \text{Transformer}(\mathbf{X}) \in \mathbb{R}^{N \times 768}, \quad N = \frac{H'}{14} \times \frac{W'}{14}
Zero-Shot Spatial Feature Geometry
  • Self-attention layers capture spatial boundaries without manual labels.
  • Token matrix \mathbf{Z} reshaped into spatial feature grid:
\mathbf{F} \in \mathbb{R}^{(H'/14) \times (W'/14) \times 768}

Substrate-Adaptive Manifold Clustering
Border-Invariant Feature Partitioning for Varied Substrates
1. Substrate Luminance Classification
  • Evaluates boundary band luminance \bar{L}_{\text{border}} to detect substrate category:
\bar{L}_{\text{border}} = \frac{1}{|\mathcal{B}|} \sum_{(x,y) \in \mathcal{B}} I_{\text{gray}}(x,y)
2. Adaptive Cluster Objectives
  • Printed Paper Mode (k=2): Variance minimization.
  • Palm-Leaf Mode (k=3): Boundary-dominant label suppression:
l_{\text{bg}} = \text{mode}\left(\mathcal{L}_{\text{boundary}}\right)
\mathcal{M}_{\text{text}} = \{ i \mid l_i \neq l_{\text{bg}} \land \bar{I}_i < \bar{I}_{\text{substrate}} \}
Section 2: Methodology
Orthographic Headline (Shirorekha) Ablation
Linear Grapheme Stem Isolation and Vertical Peak Detection
Horizontal Profile Peak Identification
  • Evaluates upper 45% vertical zone of text line ROI (y \in [0, 0.45 H_L]).
  • Headline coordinate detection formula:
P_H(y) = \sum_{x=0}^{W_L-1} B_{\text{line}}(y,x)
y^* = \arg\max_{y \in [0, 0.45 H_L]} P_H(y) \quad \text{s.t. } P_H(y^*) > 0.25 W_L
Morphological Ablation Operator
  • Zeros out headline band of dynamic thickness \tau:
B_{\text{ablated}}(y,x) = \begin{cases} 0 & \text{if } |y - y^*| \le \tau \\ B_{\text{line}}(y,x) & \text{otherwise} \end{cases}
\tau = \max(2, \lfloor 0.06 \cdot H_L \rfloor)
Section 2: Methodology
Akshara-Level Glyph Segmentation
1D Gaussian Smoothing and Valley Projection Profiles
Vertical Projection and Gaussian Smoothing
  • Computes column ink sum P_V(x) on ablated text line ROI.
  • Applies 1D Gaussian convolution to remove intra-character noise:
S_V(x) = (P_V * G_\sigma)(x) = \sum_{k=-w}^w P_V(x-k) \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{k^2}{2\sigma^2}}
Valley Minima Cut-Point Detection
  • Glyph boundaries x_k^* correspond to smoothed local minima:
\frac{\partial S_V}{\partial x} = 0, \quad \frac{\partial^2 S_V}{\partial x^2} > 0, \quad S_V(x_k^*) < \theta_{\text{valley}}
\theta_{\text{valley}} = 0.25 \cdot \left(\frac{\text{Peak}_L + \text{Peak}_R}{2}\right)
Section 2: Methodology
Multi-Column Layout Parsing and Graphic Discrimination
Vertical Projection Gutters and Spatial Density Metrics
1. Inter-Column Gutter Detection
  • Vertical projection V(x) across bounding region R.
  • Gutter condition over continuous gap length:
V_{\text{norm}}(x) = \frac{(V * G_{\sigma_c})(x)}{\max_x (V * G_{\sigma_c})(x)} < 0.02 \quad \text{for } \Delta x > \frac{W_R}{15}
2. GraphicRegion Illustration Filter
  • Evaluates ink density \rho_{\text{ink}} and valley frequency \nu_{\text{valley}}:
\rho_{\text{ink}} = \frac{1}{HW} \sum B(y,x), \quad \nu_{\text{valley}} = \frac{N_{\text{valleys}}}{H/100}
\text{GraphicRegion} \iff (\rho_{\text{ink}} > 0.30 \land \nu < 1.5) \lor (\rho_{\text{ink}} > 0.25 \land N_v < 3)
Section 2: Methodology
6-Channel Convolutional Semantic Segmentation
Instance Normalization and Multi-Scale Deep Supervision
Architectural Specifications
  • 5-level U-Net topology with strided convolutions (stride = 2).
  • Instance Normalization prevents batch-size scaling artifacts:
\text{IN}(\mathbf{x}) = \gamma \left( \frac{\mathbf{x} - \mu(\mathbf{x})}{\sqrt{\sigma^2(\mathbf{x}) + \epsilon}} \right) + \beta
Compound Multi-Scale Loss Formulation
  • Supervised at 3 decoder scales (512, 256, 128) with weights w = [1.0, 0.5, 0.25]:
\mathcal{L}_{\text{total}} = \sum_{k=0}^{2} w_k \left[ \mathcal{L}_{\text{BCE}}(\hat{Y}_k, Y_k) + \mathcal{L}_{\text{Dice}}(\hat{Y}_k, Y_k) \right]
Section 2: Methodology
Topological Discrimination of Physical Damage
Isoperimetric Quotient and Circularity Geometry
Isoperimetric Circularity Formulation
  • Punched palm-leaf binder string holes form near-perfect circles.
  • Circularity metric \Psi for internal contour \mathcal{C}:
\Psi(\mathcal{C}) = \frac{4\pi \cdot \text{Area}(\mathcal{C})}{[\text{Perimeter}(\mathcal{C})]^2}
Geometric Damage Isolation Rule
  • Contour isolated as damage if and only if:
\mathcal{C} \in \mathcal{R}_{\text{damage}} \iff \begin{cases} 500 \le \text{Area} \le 8000\text{ px} \\ \Psi(\mathcal{C}) > 0.85 \\ 0.5 \le \frac{\text{Width}}{\text{Height}} \le 2.0 \end{cases}
